## Focus

Prioritize moments where UI visuals, product surfaces, layout, typography, and motion make a concept easier to understand.

Look for:

- UI mockups
- screen captures
- white-background product or interface compositions
- clear hierarchy
- layered cards or panels
- text labels tied to visual elements
- sound hits used to punctuate UI state changes

## Ignore Unless Exceptional

- retro documentary asset texture
- purely aesthetic visuals with no explanatory value

## Evidence Reference Bias

Create references for UI layout, asset selection, information density, and sound-synced interface transitions.
